# Marc Villanueva — Portfolio

A responsive, dependency-free portfolio built with HTML, CSS, and JavaScript.

Features: dark/light themes with saved preference; mobile navigation; interactive skill explorer; scroll reveals; portrait tilt; animated decorative elements; animation pause control; reduced-motion support; expandable interest cards; share/copy link; scroll progress and active navigation.

Personal details and self-assessed skill levels are preserved from the supplied portfolio. The placeholder email has been replaced with the supplied GitHub profile. No contact form or email delivery service is required.

## Open locally
Extract this ZIP and open index.html. Alternatively, open the folder in VS Code and use Live Server. All required assets are included; no installation or build is needed. Share is enabled only on a published HTTP(S) address.

## Publish with GitHub Pages
1. Sign in to the intended GitHub account. Verify that `villanuevamarclouis-stack` is the correct username.
2. Create a public repository named `portfolio` (or use the intended existing repository).
3. Upload the extracted files, not the ZIP. Keep index.html, style.css, script.js, favicon.svg, and marc.jpg at the repository root. Include .nojekyll if using Git.
4. Commit to main.
5. Open repository Settings → Pages.
6. Choose Deploy from a branch, select main and / (root), then Save.
7. Wait for the Pages deployment to finish. GitHub will show the live URL in Settings → Pages.

If the account and repository above are used, the expected URL is https://villanuevamarclouis-stack.github.io/portfolio/ — this is an expected address, not confirmation of a live deployment.

For a root profile site, use a repository named villanuevamarclouis-stack.github.io instead.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Editing
Update personal content in index.html. Skill detail content lives in script.js. Colors, layouts, and motion are in style.css. Replace marc.jpg to change the portrait.
